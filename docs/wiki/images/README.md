# Wiki pictures

One folder per wiki page (`shaders/`, `rig/`, …) and `readme/` for the repository README's pictures.

- JPEG or WebP, at most 1200 px wide, about 300 KB or less.
- Safe for work: import with SFW mode on before taking a picture of a character.
- These files are kept out of Git LFS (see `.gitattributes`).

A page marks a picture that hasn't been made yet with a "Picture to come" line naming its file. Replace that line with the picture when you add it.
