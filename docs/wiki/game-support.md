# Game support

What works in which game.

## Exporter

| | Koikatsu | Koikatsu Sunshine | Summer Vacation Scramble |
|---|---|---|---|
| Needs | BepInEx | BepInEx | BepInEx |
| Opening the exporter window | "Show KKBP Exporter" in the maker's sidebar | "Show KKBP Exporter" in the maker's sidebar | Ctrl+Tab |
| All outfits, variations | Yes | Yes | Yes |
| Exporting a folder of cards | Yes | Yes | Yes |

## Importer

| | Koikatsu | Koikatsu Sunshine | Summer Vacation Scramble |
|---|---|---|---|
| Eevee shader, outlines | Yes | Yes | Yes |
| [Other shaders](shaders.md) | Yes | Yes | Yes; the bottom alpha mask is lost |
| [Rigify rig](rig.md), joint corrections | Yes | Yes | Yes |
| [Expressions](expressions.md), emotion grid, gag eyes | Yes | Yes | Yes |
| Tongue during mouth expressions | Moves | Moves | Stays still in most, as in the game |
| Face cards, Separate eyes | Yes | Yes | Yes |
| [Edit Material](edit-material.md) | Yes | Yes, partly approximated | No |
| [Export Prep](export-prep.md) | Yes | Yes | Yes |
| [Import Animation](animation.md) (Koikatsu animations) | Yes | Yes, untested | Yes, untested |
| [Hooks](hooks.md), Bulk Import | Yes | Yes | Yes |

Blender 5.2 or newer is needed for all of it.
